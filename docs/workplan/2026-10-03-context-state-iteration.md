## 已实现的行为

### 用户要求与交接

通用历史和活动轮保留真实用户原文及纠正顺序。最终预算裁剪仍保护这些消息；无法容纳时拒绝模型调用，避免在静默丢失要求后继续。Coding 原请求和 runtime wrapper 在起点已有分离，本轮沿用并补齐历史来源、复数 artifact_refs 和后续压缩保护。

跨任务交接保存完整的历史用户来源，并与当前任务保护块分开。历史任务不会自动变成当前任务，最新用户要求可以修改旧要求；host 摘要不能修改用户约束。历史文本和状态文本经过转义，防止工具输出伪造保护块标签。

外置用户输入增加执行前完整读取原文的明确指引；按本次输入用途判定，不依赖内容去重后可能复用的 artifact 类型。

### 压缩后的恢复

统一使用现有 read_artifact：

| 引用 | 用途 |
|---|---|
| artifact://… | 原有完整产物与工具结果 |
| event://事件ID | 当前会话的原始事件，支持分页与搜索 |
| event://session | 按关键词和事件序号范围搜索历史 |
| snapshot://快照ID | 读取摘要原文、未验证模型笔记与上一代链接 |
| state://current | 读取完整当前任务状态；返回版本与内容校验值 |

事件、快照和当前状态只从调用者自己的会话读取；父会话标识不构成读取授权。主/子 Agent 的工具注册与白名单已对齐。

累计“曾经读过”继续用于审计，是否拒绝重复读取则取决于最终模型输入里是否仍包含完整输出。可见性在 Builder 及最终 sanitizer、预算裁剪之后更新。最终 gate 删除结果、孤立工具结果被摘要化时，都允许重新装载；完整结果仍可见时保留重复保护。

访问状态的提示只展示有限资源和读取区间，完整访问记录仍留存。普通文件工具的循环计数在本会话快照变化后重置，其他会话和同代重复保护不受影响。

### 有界工作记忆和证据展示

摘要中的工具预览、引用投影与工作记忆分别受容量限制；完整事件和冷引用继续留存。上一代假设、反证、根因与后续验证进入下一代压缩输入，模型笔记始终标为未验证，不直接改变权威任务状态。

针对模型回显上一代记忆 JSON 的情况，阻止递归嵌套把有效记忆挤掉。原始模型笔记保存在快照冷层；有限模型输入和分块调用上限防止摘要调用自身失控。

真实 TaskState 投影也限制证据、覆盖和产物索引的体积，优先展示活跃声明、待验证事项与完成依据的引用。省略范围明确标记，并提供 state://current 恢复入口；不会把“没展示”解释为“不存在”或“已经验证”。原始 TaskState 不被截断。

### 代码变化后的证据有效性

read_file/read_files 把文件实际字节的 SHA-256 与工作区来源附在 host 元数据中。普通缓存和循环保护缓存都校验文件内容，外部编辑后不会继续重放旧文件并声称未变化；缓存重放保留元数据和既有工具预算语义。

Coding 证据读取真实 tool_result_ref.sha256，不再遗漏嵌套存储字段。任务上下文构建时检查已观察文件的哈希；变化或不可访问时标记旧证据过期，并把依赖它的结论和完成项置为待重验。已记录的实际写入也按事件顺序使此前测试证据失效，写入后的新验证不被当成此前验证。

模型不能通过重放旧 EvidenceRef、直接完成行动、直接宣告任务终态、去掉旧引用或多跳 supersedes 链清除待重验状态。替换被宿主标记的过期完成项需要新证据；同 patch 链式替换和循环替换被拒绝。真正补充新证据后仍可完成任务。

## 复验与边界

完整隔离后端复验：

```bash
.venv/bin/python docs/agent-design-review/implementation/evidence/final/validate_isolated_pg.py --source . --python .venv/bin/python
```

- 外置请求的“完整读取”目前是提示指引，尚未成为执行门禁；真实用户原文本身超出模型容量时，保守保护策略会明确拒绝调用。
- 跨任务交接保护了来源与原文，并未把每次 Coding 调用改成自动恢复同一个 TaskSession。
- 文件哈希覆盖已观察依赖，并保守失效此前验证；它不是全工作区版本指纹，也不能证明未观察文件没有变化。
- 只发生最终硬裁、没有新快照时，普通 read_file 的循环计数尚不按实际可见性重置；专用 artifact/event/snapshot 恢复路径已经覆盖最终可见性。
- 本轮没有调用真实付费模型、运行 SWE-bench 或比较供应商原生压缩。默认压缩阈值保持既有政策，真实模型的策略 A/B 仍需另行测量。
