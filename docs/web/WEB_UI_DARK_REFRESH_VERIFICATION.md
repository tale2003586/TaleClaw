# taleclaw Web UI 暗色改版与验证记录

> 验证日期：2026-05-31  
> 验证范围：`web/static/index.html`、`web/static/app.js`、`web/static/styles.css`，以及 Web 服务已有 API 和回归测试。  
> 结论：本轮 UI 调整可以正常使用，未发现阻断性问题。

## 一、本轮 UI 改动概览

### 1. 暗色视觉体系

- 将页面从浅色工作台调整为暗色界面。
- 重设背景、表面、边框、正文、弱化文字、强调色和阴影变量。
- 使用半透明表面与 `backdrop-filter`，形成轻量玻璃质感。
- 增加选中文字样式和细窄滚动条。
- 保持侧栏与主聊天区域分离，底部输入区继续独立固定。

### 2. 品牌和状态区

- 为 `taleclaw` 增加品牌图形。
- 增加内联 favicon。
- 在线状态增加圆点提示。
- 当前会话标题增加 presence dot。
- 模式切换区增加 `Mode` 标签。

### 3. 会话列表

- 会话行增加 hover 位移反馈。
- 当前会话使用强调色边框和左侧高亮线。
- Web 会话支持删除按钮。
- 忙碌状态下删除按钮会被禁用，避免请求执行期间删除活动会话。

### 4. 聊天阅读体验

- 助手消息继续使用服务端生成的安全 Markdown HTML。
- 标题、列表、引用、行内代码和代码块拥有暗色主题样式。
- 代码块增加“复制”按钮。
- 复制成功后显示“已复制!”，剪贴板不可用时显示“失败”。
- 消息增加轻量进入动画。
- 工具请求和工具结果继续使用默认折叠的 `<details>`，需要时再展开。

### 5. 滚动和输入框行为

- 新增“接近底部才自动滚动”的策略。
- 用户向上阅读历史消息时，重新渲染不会强制跳到底部。
- 新消息、流式消息和切换会话时仍可强制滚动到底部。
- 输入框根据内容自动增高，最大高度限制为 `180px`。
- 发送后输入框恢复初始高度。

### 6. 响应式和可访问性

- 手机端继续使用左上角按钮控制抽屉式侧栏。
- 抽屉打开后更新 `aria-expanded`。
- 搜索框和分析文本框补充 `aria-label`。
- 搜索框关闭自动补全。
- 输入框关闭拼写检查。
- 文件页和分析页的手机端侧栏按钮补充 `aria-controls` 和初始 `aria-expanded`。

## 五、结论与注意事项

本轮 UI 可以正常投入使用。暗色主题、工具折叠、代码复制、阅读位置保持、输入框自动增高和手机侧栏均已通过实际浏览器验证。

注意事项：

- 剪贴板写入依赖浏览器权限和页面焦点。真实用户点击时通常满足焦点条件，失败时页面也有明确反馈。
- Markdown 代码块允许自身横向滚动，用于展示长代码；页面整体不会被代码内容撑宽。
- 本轮验证未修改你的 UI 实现，仅新增此记录文件。
